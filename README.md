# TWM Market

Неофициальная торговая площадка игроков **Amazing Online**: рынок предметов, авторынок и нотариальная контора в одном настольном приложении для Windows.

> TWM Market не связан с разработчиками Amazing Online. Площадка помогает игрокам найти друг друга, но не участвует в сделках и не гарантирует передачу имущества — все сделки проходят в игре.

## Статус

Проект в разработке. Готовы аккаунты и игровые профили, админ-панель со справочниками и журналом действий, а также объявления: подача со скриншотами, каталоги трёх разделов с фильтрами, карточки, поиск и избранное. Чат с продавцом, уведомления и модерация — в следующей версии.

Стартовое наполнение справочников:

- **Рынок предметов** — 10 категорий павильонов и 232 аксессуара (по видео из игры). У аксессуаров и одежды есть поле «Улучшение» (X1–X15), у одежды — «Целостность».
- **Авторынок** — 266 моделей транспорта из темы [«Таблица транспорта»](https://forum.amazing-online.com/threads/tablitsa-transporta-tseny-sposoby-polucheniya.965355/) на форуме (актуально на 21.08.2026), разбитых на 5 типов, и 20 полей характеристик с экрана авто в игре. Поле «Фары» выключено, пока в него не внесены цвета.

Всё это правится в админ-панели: «Справочники» и «Конструктор полей». Поле можно привязать к отдельным категориям и задать шаг значения (например, клиренс 5, 10, … 100 %).

| Шаг | Что входит | Статус |
|---|---|---|
| 1 | Каркас, сборка .exe на GitHub, дизайн-система | готов |
| 2 | База данных, регистрация, вход, игровые профили | готов |
| 3 | Справочники и админ-панель | готов |
| 4 | Объявления, скриншоты, каталоги, поиск | готов |
| 5 | Чат, избранное, уведомления, жалобы, модерация | — |
| 6 | Статистика, средние цены, автообновление, первый выпуск | — |

## Почему исходный код открыт

Приложение распространяется как `.exe`, а в игровых сообществах неизвестные программы — частый способ украсть аккаунт. Поэтому:

- весь код открыт, любой может проверить, что делает программа;
- установщики собираются **только на серверах GitHub** из кода этого репозитория (см. вкладку *Actions*);
- выпуски публикуются **только** во вкладке [Releases](../../releases) вместе с файлом `SHA256SUMS.txt`.

### Как проверить скачанный установщик

В PowerShell:

```powershell
Get-FileHash .\TWM.Market_0.1.0_x64-setup.exe -Algorithm SHA256
```

Значение должно совпасть с `SHA256SUMS.txt` из того же релиза. Если не совпадает — не запускайте файл.

Пока установщик не подписан сертификатом, Windows может показать окно «Система Windows защитила ваш компьютер». Это ожидаемо для новых неподписанных программ: нажмите «Подробнее» → «Выполнить в любом случае», только если файл скачан из Releases этого репозитория и контрольная сумма совпала.

## Разработка

Нужны:

- [Node.js 22](https://nodejs.org/) и pnpm (`corepack enable`);
- для запуска окна приложения — [Rust](https://www.rust-lang.org/tools/install) и WebView2 (уже есть в Windows 10/11).

- для сервера — PostgreSQL 15+ (проще всего через [Docker](https://www.docker.com/)).

```bash
pnpm install          # зависимости + сборка packages/shared

docker compose up -d  # база данных для разработки
cp apps/api/.env.example apps/api/.env   # и впишите свои JWT_SECRET и CODE_SECRET

pnpm dev:api          # сервер на http://localhost:3000 (миграции применяются при запуске)
pnpm dev:desktop      # окно приложения с горячей перезагрузкой
pnpm dev:ui           # только интерфейс в браузере, без Rust

pnpm typecheck        # проверка типов
pnpm test             # тесты
```

Настройки задаются переменными окружения: примеры в `apps/api/.env.example` и `apps/desktop/.env.example`. Файлы `.env` в репозиторий не попадают.

Фото объявлений и иконки предметов сохраняются в папку `UPLOAD_DIR` (по умолчанию `apps/api/data/uploads`). На сервере это должен быть постоянный диск, иначе файлы пропадут при перезапуске.

Письма на этапе разработки не отправляются, а выводятся в журнал сервера — код подтверждения смотрите там.

Интеграционные тесты сервера работают с настоящей базой. Укажите отдельную пустую базу в `TEST_DATABASE_URL` — тесты очищают её таблицы. Без этой переменной тесты базы пропускаются.

### Администратор

Через приложение стать администратором нельзя. Первый администратор создаётся командой на сервере:

```bash
pnpm --filter @twm/api admin:create -- --login admin_max --email you@example.com
```

Пароль запрашивается с клавиатуры (ввод скрыт). При первом входе в админ-панель приложение попросит включить двухфакторный вход (Google Authenticator, Яндекс Ключ, Aegis и т. п.) — без него админ-панель не открывается.

Если администратор потерял телефон, двухфакторный вход сбрасывается только на сервере:

```bash
pnpm --filter @twm/api admin:reset-2fa -- --login admin_max
```

### Роли

| Роль | Что может |
|---|---|
| Модератор | Дашборд, просмотр пользователей и справочников. Модерация объявлений — на шаге 5 |
| Администратор | Всё, что модератор, плюс блокировка игроков, редактирование справочников, журнал действий |
| Суперадминистратор | Всё, плюс назначение ролей. Создаётся только командой на сервере |

Все действия администрации записываются в журнал. Записи журнала нельзя изменить или удалить — это запрещено триггером в базе данных.

## Как устроена безопасность аккаунтов

- Пароли хранятся только как хеш **Argon2id**.
- Вход выдаёт короткий токен доступа (15 минут, только в памяти) и токен обновления. Токен обновления хранится в «Диспетчере учётных данных» Windows, а на сервере — только его хеш.
- При каждом обновлении выдаётся новый токен. Если старый предъявят повторно (признак кражи), сессия закрывается.
- После 5 неверных паролей вход блокируется на 15 минут; частота запросов к входу и регистрации ограничена.
- Смена или сброс пароля завершают сессии на других устройствах. Список устройств и выход с них — в личном кабинете.
- Сообщения об ошибке входа одинаковые для неверного пароля и несуществующего логина, а восстановление пароля не раскрывает, зарегистрирован ли email.
