# TWM Market для Amazing Online (прототип)

32-битный DLL-модуль для загрузки через quick_asi.exe из папки `asi`.
`Ctrl+Shift+M` рисует панель в кадре Direct3D 9. В ней есть два экрана:
активные объявления с числом непрочитанных сообщений и сведения о переписке
с согласованной ценой. Клавиши `1` и `2` переключают экраны, `O` открывает соответствующий раздел TWM Market.

Плагин не считывает игровые данные и не содержит токены входа. Для вывода панели он перехватывает вызов Direct3D 9 через установленный в игре MinHook.x86.dll.
Windows-приложение TWM Market обновляет локальный снимок данных раз в 30 секунд
в `%LOCALAPPDATA%\TWM Market\game-overlay.txt`. Без запущенного приложения
плагин показывает приглашение войти.

Это экспериментальная сборка для эксклюзивного полноэкранного режима.
