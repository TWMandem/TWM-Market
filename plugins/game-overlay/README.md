# TWM Market для Amazing Online (прототип)

32-битный DLL-модуль для загрузки через quick_asi.exe из папки `asi`.
`Ctrl+Alt+F10` показывает панель в кадре Direct3D 9. Вкладки «Мои объявления»,
«Переписки» и «Настройки» переключаются внутренним курсором. Он появляется
в центре панели и получает относительное движение мыши через DirectInput, поэтому
не зависит от видимости системного указателя. Внизу панели можно открыть соответствующий
раздел Windows-приложения TWM Market. Панель показывает активные объявления,
непрочитанные сообщения и до трёх открытых переписок с согласованной ценой,
если она есть. Место и время встречи стороны обсуждают в чате приложения.

Плагин не считывает игровые данные и не содержит токены входа. Для вывода
панели он перехватывает вызов Direct3D 9 через установленный в игре MinHook.x86.dll.
Windows-приложение TWM Market 0.24.2 или новее обновляет локальный снимок данных раз в 30 секунд
в `%LOCALAPPDATA%\TWM Market\game-overlay.txt`. Без запущенного приложения
плагин показывает подсказку о запуске приложения. В настройках выбираются положение
панели, скорость курсора и показ горячей клавиши; выбор хранится в
`%LOCALAPPDATA%\TWM Market\game-overlay.ini`. Версия для Android и сайт
не создают этот файл на компьютере игрока.

Вывод панели в эксклюзивном полноэкранном режиме проверен игроком. Управление
мышью и передача данных из Windows-приложения требуют проверки на его установке.
