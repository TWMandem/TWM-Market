# TWM Market для Amazing Online (прототип)

32-битный DLL-модуль для загрузки через quick_asi.exe из папки `asi`.
`Ctrl+Shift+M` показывает небольшое окно поверх игры. В нём есть два экрана:
активные объявления с числом непрочитанных сообщений и сведения о переписке
с согласованной ценой. Кнопка открывает соответствующий раздел TWM Market.

Плагин не читает память игры, не отправляет команды и не содержит токены входа.
Windows-приложение TWM Market обновляет локальный снимок данных раз в 30 секунд
в `%LOCALAPPDATA%\TWM Market\game-overlay.txt`. Без запущенного приложения
плагин показывает приглашение войти.

Окно Win32 рассчитано на оконный или безрамочный режим игры. Поверх
эксклюзивного полноэкранного режима его отображение не гарантируется.
