# Изменения

Раздел выпуска начинается с `## vX.Y.Z`. Текст раздела попадает в описание
релиза на GitHub и в окно «Что нового» при автообновлении приложения.

## v0.6.0

Первый официальный выпуск TWM Market.

- Рынок предметов, авторынок и нотариальная контора: объявления со скриншотами, каталоги с фильтрами, поиск, избранное.
- Переписка с продавцом, отметка сделки и отзывы, уведомления Windows, работа из трея.
- Жалобы и модерация, стоп-слова против торговли за реальные деньги.
- История цены предмета или модели, похожие предложения, статистика своих объявлений.
- Подписки на поиск: уведомление, когда появится подходящее объявление.
- Автообновление: приложение само проверяет новые версии и ставит их по кнопке.
